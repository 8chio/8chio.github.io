## 시작하며

[지난 글](/posts/chatgpt-google-calendar/)에서는 ChatGPT와 Google Calendar를 연결해 자연어로 일정을 조회하고 등록해봤습니다.

Calendar 연동은 약속이나 병원 예약처럼 **언제 해야 하는지가 중요한 일정**을 관리할 때 편했습니다.

하지만 운동, 공부, 블로그 글쓰기처럼 매일 해야 하는 일까지 Calendar에 넣기 시작하면 일정 화면이 금방 복잡해집니다.

그래서 일정과 할 일의 역할을 다음처럼 나누기로 했습니다.

```text
시간이 중요한 일정
        ↓
Google Calendar

해야 할 일과 반복 루틴
        ↓
Notion To-do

두 서비스를 자연어로 다루는 인터페이스
        ↓
ChatGPT
```

이번 글에서는 직접 만든 **Notion To-do 데이터베이스**를 소개하고, ChatGPT와 연결해 할 일을 조회하고 추가하거나 완료 처리했던 과정을 정리했습니다.

## 1. 현재 사용 중인 To-do 구성

먼저 Notion에 `To-do` 데이터베이스를 만들었습니다.

단순히 할 일과 체크박스만 두기보다는 반복 루틴과 일반 할 일을 하나의 데이터베이스에서 관리할 수 있도록 구성했습니다.

<!-- TODO: 실제 To-do 데이터베이스 전체 화면 캡처. 업무 및 개인 정보는 마스킹 -->
![Notion To-do 데이터베이스 전체 화면](/assets/img/posts/chatgpt-notion-todo/notion-todo-overview.png)
*반복 루틴과 일반 할 일을 하나의 데이터베이스에서 관리하고 있습니다.*

사용 중인 속성은 다음과 같습니다.

| 속성  | 형식     | 용도                                |
| ----- | -------- | ----------------------------------- |
| 할 일 | 제목     | 해야 할 일의 이름                   |
| 완료  | 체크박스 | 완료 여부 확인                      |
| 날짜  | 날짜     | 실행할 날짜 지정                    |
| 유형  | 선택     | `루틴`과 `일반` 구분                |
| 반복  | 선택     | `없음`, `매일`, `평일`, `주말` 구분 |
| 영역  | 선택     | `ME`, `HOME`, `WORK` 구분           |
| 메모  | 텍스트   | 세부 내용이나 참고사항 기록         |

`영역`은 할 일의 성격을 구분하기 위해 사용했습니다.

```text
ME    → 운동, 공부, 독서, 블로그 등 개인 영역
HOME  → 생활비, 장보기, 차량 관리 등 생활 영역
WORK  → 업무와 관련된 할 일
```

`유형`과 `반복`은 서로 비슷해 보이지만 역할이 다릅니다.

- `유형`은 루틴인지 일반 할 일인지를 구분합니다.
- `반복`은 해당 루틴이 언제 반복되는지를 표시합니다.

예를 들어 평일마다 하는 아침 운동은 다음과 같이 기록합니다.

```text
할 일 : 05:15 아침운동
완료   : 미완료
날짜   : 오늘
유형   : 루틴
반복   : 평일
영역   : ME
```

반면 한 번만 처리하면 되는 차량 요금제 해지 같은 항목은 `일반`, `반복 없음`, `HOME`으로 구분합니다.

## 2. 필요한 정보만 볼 수 있도록 View 나누기

하나의 데이터베이스에 모든 항목을 저장하되, 실제로 사용할 때는 View를 나누어 필요한 정보만 확인하도록 했습니다.

현재 사용하는 View는 다음과 같습니다.

| View   | 표시하는 내용                         |
| ------ | ------------------------------------- |
| 오늘   | 오늘 날짜이면서 완료되지 않은 항목    |
| 이번주 | 이번 주에 해야 하는 미완료 항목       |
| 미완료 | 날짜와 관계없이 끝나지 않은 모든 항목 |
| 루틴   | 완료되지 않은 반복 루틴               |
| 일반   | 완료되지 않은 일반 할 일              |
| 완료   | 완료 체크한 항목                      |
| 캘린더 | 날짜를 기준으로 보는 할 일            |
| 전체   | 모든 항목                             |

## 3. 반복 루틴은 Notion 반복 템플릿으로 만들기

처음에는 ChatGPT가 매일 루틴을 생성하도록 만드는 방법도 생각했습니다.

하지만 이 방식은 매일 정해진 시간에 실행되는 별도의 예약 작업이 필요하고, ChatGPT의 예약 작업 하나를 계속 사용하게 됩니다.

이미 Notion 자체에 **반복 템플릿** 기능이 있기 때문에 반복 생성은 Notion에 맡기기로 했습니다.

현재는 다음과 같은 루틴을 각각 데이터베이스 템플릿으로 만들어 사용하고 있습니다.

```text
매일
└─ 05:00 기상

평일
├─ 05:15 아침운동
├─ 06:35 성장시간
├─ 19:40 자유/성장 시간
├─ 21:00 일기/하루정리
└─ 22:00 취침
```

반복 템플릿이 매일 또는 평일에 맞춰 실제 To-do 항목을 생성하면, 생성된 항목은 일반 할 일과 함께 `오늘` View에 나타납니다.

<!-- TODO: 데이터베이스 템플릿 목록 또는 반복 설정 화면 캡처 -->
![Notion To-do 반복 템플릿 설정](/assets/img/posts/chatgpt-notion-todo/notion-recurring-template.png)
*반복 루틴 생성은 ChatGPT가 아니라 Notion 반복 템플릿에 맡겼습니다.*

역할을 정리하면 다음과 같습니다.

| 기능                        | 담당               |
| --------------------------- | ------------------ |
| 반복되는 루틴 자동 생성     | Notion 반복 템플릿 |
| 오늘 할 일 표시와 완료 기록 | Notion To-do       |
| 새로운 할 일 입력·조회·수정 | ChatGPT            |

이렇게 나누니 반복 작업을 위해 별도의 예약 작업을 만들 필요가 없고, ChatGPT는 필요할 때 대화로 To-do를 관리하는 역할에 집중할 수 있었습니다.

ChatGPT의 설정 화면에서 **플러그인 → Notion**으로 이동한 뒤 사용할 Notion 계정을 연결하고 접근 권한을 승인했습니다.

개인적인 기록이 많은 페이지까지 모두 연결하기보다는 자동화에 사용할 To-do 데이터베이스를 중심으로 필요한 범위만 허용했습니다.

## 5. ChatGPT에서 오늘 할 일 조회하기

연결이 끝난 뒤 가장 먼저 읽기 기능부터 확인했습니다.

ChatGPT에게 다음처럼 요청했습니다.

> "Notion To-do에서 오늘 해야 할 일 알려줘."

ChatGPT가 `오늘` 날짜와 완료 여부를 확인하고 아직 끝나지 않은 항목을 찾아줬습니다.

이때 데이터베이스에 `오늘` View가 있더라도, ChatGPT는 View 이름만 보는 것이 아니라 날짜와 완료 속성을 기준으로 항목을 확인할 수 있습니다.

예를 들어 영역을 함께 지정하면 필요한 항목만 좁혀서 볼 수도 있습니다.

> "오늘 할 일 중에서 WORK 영역만 알려줘."

> "이번 주에 끝내지 못한 일반 할 일만 알려줘."

Notion 앱을 열고 여러 View를 이동하지 않아도 대화만으로 필요한 항목을 확인할 수 있다는 점이 편했습니다.

## 7. 할 일 수정하고 완료 처리하기

새로운 항목을 추가하는 것뿐 아니라 기존 항목을 수정하는 것도 테스트했습니다.

예를 들면 다음처럼 요청할 수 있습니다.

> "방금 만든 To-do 연동 테스트의 영역을 WORK로 바꿔줘."

> "To-do 연동 테스트 완료 처리해줘."

완료 처리를 요청하자 해당 항목의 `완료` 체크박스가 선택됐습니다.

완료된 항목은 `오늘`과 `미완료` View에서는 사라지고 `완료` View에서 확인할 수 있었습니다.

```text
ChatGPT에 완료 요청
        ↓
Notion에서 같은 이름의 항목 확인
        ↓
완료 체크박스 변경
        ↓
미완료 View에서 제외
        ↓
완료 View에서 확인
```

## 8. 실제로 사용할 때의 요청 방법

ChatGPT가 데이터베이스 구조를 알고 있더라도 요청할 때 필요한 속성을 함께 말하면 결과가 더 정확했습니다.

제가 주로 사용하는 요청 형태는 다음과 같습니다.

### 오늘 할 일 확인

> "Notion To-do에서 오늘 미완료 할 일 알려줘."

### 일반 할 일 추가

> "9월 28일에 Kia Connect 요금제 해지하기를 HOME 영역의 일반 할 일로 추가해줘. 반복은 없음이야."

### 업무 할 일 추가

> "내일 체크리스트 정리하기를 WORK 영역의 일반 할 일로 추가해줘."

### 완료 처리

> "오늘 아침운동 완료 처리해줘."

### 날짜나 메모 수정

> "Kia Connect 요금제 해지 날짜를 9월 29일로 바꾸고 메모에 고객센터 번호를 추가해줘."

이름이 비슷한 항목이 여러 개 있을 때는 날짜나 영역을 같이 말해주는 편이 안전합니다.

예를 들어 `아침운동 완료 처리해줘`보다 `오늘 날짜의 05:15 아침운동을 완료 처리해줘`라고 요청하면 수정할 대상을 더 정확하게 찾을 수 있습니다.

## 9. To-do 템플릿 공유

제가 사용하는 원본 To-do에는 개인 일정과 업무 내용이 들어 있기 때문에 원본 데이터베이스를 그대로 공개하지 않았습니다.

대신 개인 데이터를 제거하고 속성과 View만 남긴 **공유용 To-do 템플릿**을 별도로 만들었습니다.

공유용 템플릿에는 다음 구성이 포함됩니다.

- `할 일`, `완료`, `날짜`, `유형`, `반복`, `영역`, `메모` 속성
- 전체, 미완료, 루틴, 일반, 완료 View
- 날짜를 기준으로 확인하는 캘린더 View
- `ME`, `HOME`, `WORK` 영역 구분
- `없음`, `매일`, `평일`, `주말` 반복 구분


[☑️ Notion To-do 템플릿 복제하기](https://app.notion.com/p/e2be9322e9804bb4a94d1dca2a8d16c0?v=01d509d4b8454992a247e60d49287cb3&source=copy_link)

링크를 연 뒤 오른쪽 위의 **복제**를 선택하면 자신의 Notion 워크스페이스로 가져갈 수 있습니다.

복제한 뒤에는 자신의 생활 방식에 맞춰 영역과 반복 옵션을 수정하면 됩니다.

### 오늘과 이번주 View 만들기

공유용 템플릿을 복제한 뒤 다음 필터를 사용하면 `오늘`과 `이번주` View를 만들 수 있습니다.

```text
오늘 View
날짜 → 오늘
완료 → 체크되지 않음

이번주 View
날짜 → 이번 주
완료 → 체크되지 않음
```

### 반복 루틴 만들기

반복 루틴은 데이터베이스 템플릿을 만든 뒤 Notion 화면에서 반복 주기를 직접 설정해야 합니다.

예를 들어 평일 아침 운동을 만들려면 다음 값을 기본값으로 지정합니다.

```text
할 일 : 05:15 아침운동
유형   : 루틴
반복   : 평일
영역   : ME
```

그다음 템플릿 메뉴에서 반복 주기를 `매주 월요일부터 금요일`에 맞게 설정합니다.

루틴마다 생성 시간이 꼭 실제 실행 시간일 필요는 없습니다. 해당 날짜의 `오늘` View에 나타나는 것이 목적이라면 하루가 시작되기 전이나 이른 아침에 생성되도록 설정하면 됩니다.

## 사용하면서 느낀 점

이번 구성을 사용하면서 가장 편했던 점은 Notion의 구조를 유지한 채 입력 방법만 단순해졌다는 것입니다.

예전에는 Notion을 열고 데이터베이스를 찾은 뒤 새 페이지를 만들고 각 속성을 하나씩 선택해야 했습니다.

지금은 ChatGPT에게 평소 말하듯 요청하면 됩니다.

```text
"내일 아침 러닝 추가해줘"
        ↓
ChatGPT가 요청 해석
        ↓
Notion To-do에 항목 생성
        ↓
오늘 또는 이번주 View에서 확인
        ↓
완료 후 체크
```

반복 생성은 Notion, 데이터 저장과 View는 To-do 데이터베이스, 자연어 입력은 ChatGPT가 담당하도록 역할을 나누니 구조도 단순해졌습니다.

다만 기존 항목을 수정하거나 삭제할 때는 이름이 같은 항목이 있는지 확인하는 과정이 필요합니다.

특히 완료 처리처럼 기존 데이터를 바꾸는 요청은 **할 일 이름, 날짜, 영역**을 함께 말하고 ChatGPT가 찾은 항목이 맞는지 확인한 뒤 처리하는 편이 안전했습니다.

## 마무리

Google Calendar 연동에 이어 Notion To-do까지 연결하면서 일정과 할 일을 대화로 관리할 수 있는 기본 구조가 만들어졌습니다.

```text
Google Calendar
└─ 약속, 예약, 시간 중심 일정

Notion To-do
├─ 일반 할 일
├─ 매일·평일·주말 반복 루틴
└─ 완료 기록

ChatGPT
└─ 조회, 추가, 수정, 완료를 위한 자연어 인터페이스
```

새로운 일정 관리 앱으로 옮긴 것이 아니라, 기존에 사용하던 Calendar와 Notion을 그대로 두고 ChatGPT라는 입력 방법을 하나 추가한 셈입니다.
